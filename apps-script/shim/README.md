# STRATEGY-KIT shim — 受講者貼付用 v0.11.0

受講者は **このディレクトリの `Code.gs` を1回貼り付けるだけ**で
STRATEGY-KIT の全機能が使えるようになります。
以降のロジック更新は山口さん側のライブラリで行われ、自動的に反映されます。

---

## セットアップ手順（受講者向け・7ステップ）

### Step 1: マスタードキュメントを開く

戦略マスタードキュメント（テンプレートからコピーした Google ドキュメント）を開きます。
**初めての方**は、まず山口さんから配布されたテンプレート Doc を自分の Drive にコピーしてください。

### Step 2: Apps Script を開く

ドキュメント上部のメニュー → **拡張機能 → Apps Script**
→ 新しい Apps Script プロジェクトが開きます

### Step 3: ライブラリを追加

1. 左サイドバー「**ライブラリ**」横の「**＋**」をクリック
2. スクリプト ID 欄に **山口さんから受け取ったライブラリのスクリプト ID** を貼り付け
3. 「検索」→ `StrategyKitLib` が表示されたら選択
4. 「バージョン」: **HEAD（開発モード）** を選択（自動アップデート用）
5. 「ID」: `StrategyKitLib` のまま（変更しないこと）
6. 「追加」をクリック

### Step 4: shim/Code.gs を貼り付け

1. 左サイドバー「**ファイル**」の `Code.gs` を開く
2. 既存の中身を全て削除
3. このディレクトリの `Code.gs` の中身を全部コピペ
4. 保存（Cmd/Ctrl + S）

### Step 5: Web App としてデプロイ

1. エディタ右上「**デプロイ**」→「**新しいデプロイ**」
2. 種類を選択 → 歯車 →「**ウェブアプリ**」
3. 説明: `STRATEGY-KIT v0.11`
4. 次のユーザーとして実行: **自分**
5. アクセスできるユーザー: **Google アカウントを持っているユーザー全員**（重要：「全員（匿名）」にしない）
6. 「デプロイ」→ 必要な権限を承認

#### 「このアプリは Google で確認されていません」警告について
受講者自身がデプロイした自作アプリのため、初回承認時に「Google で確認されていません」警告が出ます。これは正常な動作です：
- 「**詳細**」→「**(あなたの Google アカウント名)に移動（安全ではないページ）**」をクリック
- 続けて権限承認を最後まで通します

7. 表示された **ウェブアプリ URL** を控える

### Step 6: Chrome 拡張のオプションに登録

Chrome 拡張機能のオプション画面（拡張アイコンを右クリック → オプション）で
GAS Web App URL 欄に Step 5 で得た URL を貼り付けます。

### Step 7: 動作確認

**ドキュメントを再読み込み**（必須・タブを閉じて開き直す）すると、メニューバーに **STRATEGY-KIT** が表示されます。
**STRATEGY-KIT → テンプレート原本セットアップ（初回のみ）** を実行して、
山口さんから配布されたテンプレート原本 Doc の URL を入力してください。

> ⚠️ **テンプレート原本 Doc では他のメニューを実行しないでください**。テンプレートが破壊されるリスクがあります。新規案件は必ず「新規マスタードキュメント作成」から行います。

## このシムが含む内容

| 区分 | 内容 |
|---|---|
| `onOpen` | メニュー作成（ライブラリでは定義不可なため shim で必須） |
| `doPost` / `doGet` | Web App エンドポイント。`StrategyKitLib.route()` に委譲 |
| `sk_*` | 各メニューハンドラ。`StrategyKitLib.ui*()` に委譲 |
| `GEMINI` / `GEMINI_BATCH` | スプレッドシート用カスタム関数（任意） |
| `_props_()` | 受講者の ScriptProperties をライブラリへ渡すヘルパ |

合計約 100 行。中身を読み解く必要はありませんが、変更したい場合は
`onOpen` のメニュー定義のみ調整可能です（メニュー項目の名前・並び順）。

---

## アップデート時の手順

ロジック側は山口さんが更新すれば自動反映されます（HEAD モード）。
**shim を更新する必要はありません**。

ただし以下のケースだけ shim を再貼付してください：
- 新しいメニュー項目が追加されてアナウンスがあったとき
- ライブラリの公開インターフェースに破壊的変更があり、新バージョンを固定するよう指示されたとき

## トラブルシュート

### 「StrategyKitLib is not defined」

- ライブラリの追加（Step 3）が正しく完了していません
- スクリプト ID が正しいか確認（山口さんの最新案内をチェック）

### 「Cannot call DocumentApp.getUi() from this context」

- これは Apps Script エディタの「実行」ボタンから関数を直接実行したときのみ発生する正常な挙動
- ドキュメント側のメニューから実行すれば問題なし

### 「権限がありません」

- Web App 作成時の OAuth 承認をスキップしている可能性
- もう一度デプロイし直して、承認画面を最後まで通してください

### Gemini API が動かない

- スクリプトプロパティに `GEMINI_API_KEY` が登録されているか確認
- プロジェクト設定（歯車アイコン）→「スクリプト プロパティ」→「スクリプト プロパティを編集」→ 追加
- API キーは <https://aistudio.google.com/app/apikey> で無料取得可能
