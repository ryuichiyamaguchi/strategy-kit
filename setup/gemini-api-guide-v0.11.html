Part 1 — 5分・概念説明

そもそも「API」って何？

「API（エーピーアイ）」という言葉を聞いたことがある方も多いと思います。
難しく聞こえますが、ChatGPT を例にとると理解しやすくなります。

ChatGPT を使う 2 つの方法

方法 A：ブラウザ画面から使う（今あなたがやっている方法）

chatgpt.com をブラウザで開いて、テキストボックスに文字を打ち込む。
画面で返事を受け取る。
人間が操作して使う。

方法 B：プログラム経由で使う（API を使う方法）

拡張機能（プログラム）が自動で AI に質問を送り、返事を受け取る。
人間は「開始ボタン」を押すだけ。
プログラムが代わりに操作する。

API＝プログラム同士の「話す言葉」

API（Application Programming Interface）とは、プログラム同士がやりとりするための「決まった話し方の形式」です。
難しく言うとそうなりますが、受講者のみなさんにとって一番大事なことは：

拡張機能が「受講者の代わりに Gemini に質問するためのドア」が API です。
そのドアを開けるための「鍵」が API キー です。

図解：2 つの使い方の違い

── 方法A：ブラウザ画面から使う ────────────────────────── あなた（人間） │ │ テキストボックスに文字を打つ ▼ ChatGPT の画面 │ │ 内部で AI に送信・受信 ▼ 返答が画面に表示される ── 方法B：API を使う（拡張機能が代わりに動く） ────────────── あなた（「開始」ボタンを押すだけ） │ ▼ STRATEGY-KIT 拡張機能（プログラム） │ │ API キーを使ってリクエストを送る ▼ Gemini API（プログラム用の入口） │ │ AI が処理・返答 ▼ 拡張機能がスプレッドシートに書き込む
ポイント：STRATEGY-KIT の「半自動」「全自動」モードは方法 B で動いています。だから API キーが必要なのです。
Part 2

Google AI Studio と Google Cloud Platform の違い

Gemini API を調べると「Google AI Studio」と「Google Cloud Platform（GCP）」の 2 つの名前が出てきます。
違いが分からなくて混乱する方がとても多いので、しっかり整理します。

2 つのサービスの比較

Google AI Studio Google Cloud Platform（GCP）
目的 AI モデルを試す・API キーを発行する クラウドインフラ全般（サーバー・データベースなど）
対象 個人・開発者・初学者 企業・本格的な開発チーム
料金 API キーは無料で取得可能 プロジェクト作成は無料、使用量に応じて課金
受講者が触るのは？ これだけで OK 触らなくていい

「内部的には GCP」だが意識しなくていい理由

Gemini API は技術的には GCP のサービスの一部として動いています。
しかし Google AI Studio から API キーを発行すれば、GCP のコンソール画面を一切触らずに使えます。

受講者がやること
  • Google AI Studio にアクセス
  • API キーを発行
  • GAS のスクリプトプロパティに登録
やらなくていいこと
  • GCP コンソール（console.cloud.google.com）
  • 請求先アカウントの設定
  • プロジェクトの詳細設定
覚えるのはこれだけ：Gemini API を使うには Google AI Studio（aistudio.google.com）だけ触ればよい。GCP は関係ない。
Part 3

Gemini の無料枠はどうなってるの？

「無料枠」という言葉があると、「いつか課金されるのでは？」と不安になる方もいると思います。
仕組みを理解すれば心配する必要はありません。

主要モデルの無料枠（2025年時点）

モデル 1分あたり
リクエスト数		 1日あたり
リクエスト数		 月の入力
トークン		 用途
gemini-2.5-flash
★ 推奨		 10 250 1M STRATEGY-KIT デフォルト
gemini-2.5-flash-lite 15 1,000 1M より多く使いたい場合
gemini-2.5-pro （少ない） （少ない） — 高精度・無料枠は厳しい

※ 「トークン」とは AI が処理するテキストの単位。日本語は 1 文字 ≒ 1〜2 トークン。1M = 100万トークン。

重要ポイント：クレカ未登録なら課金は物理的に不可能

クレカ未登録の場合（推奨）
  • 請求先アカウントが存在しない
  • 物理的に課金できない
  • 上限超過時は「429 エラー」が出るだけ
  • 1 分待てば再び使える
上限に当たった場合の症状
  • 「429 RESOURCE_EXHAUSTED」エラー
  • 拡張機能が一時停止する
  • データは消えない・損害なし
  • 1 分以上待ってリトライで解決

半自動・全自動モードでの無料枠への影響

モード 無料枠との相性 理由
半自動 問題なし（推奨） 1 フェーズごとに確認待ちが入るため、分単位制限に当たりにくい
全自動 可能だが注意 9〜10 フェーズを連続実行するため、10 RPM 制限に当たる可能性あり
当面の推奨：半自動モードを使う。1 フェーズずつ AI の出力を確認しながら進められる上、無料枠の制限にも当たりにくいため、初めての方に最適です。
Part 4

API キーの取得手順

ここからは実際に手を動かします。
所要時間は 5〜10 分です。順番通りに進めれば必ず取得できます。

始める前に確認：Google アカウントでログインできる Chrome ブラウザを開いておいてください。

Step 1 — Google AI Studio にアクセス

  1. Chrome で https://aistudio.google.com/app/apikey を開きます。
  2. Google アカウントのログイン画面が出たら、普段使っている Gmail アドレスでログインしてください。
  3. ログイン後、「API keys」または「API キー」という画面が表示されれば OK です。
[スクショ: aistudio.google.com/app/apikey にアクセスした直後の「API keys」一覧画面]
URL を直接入力するのが確実です。「Google AI Studio」で検索すると別のページに飛ぶことがあります。

Step 2 — 「API キーを作成」をクリック

  1. 画面上部にある「Create API key」（または「API キーを作成」）ボタンをクリックします。
  2. ダイアログ（小さなウィンドウ）が表示されます。
[スクショ: 「Create API key」ボタンの位置（画面上部・緑色のボタン）]

Step 3 — 「新しいプロジェクトで API キーを作成」を選ぶ

  1. ダイアログに「既存のプロジェクトで作成」と「新しいプロジェクトで作成」の 2 択が表示されます。
  2. 「新しいプロジェクトで作成」を選択します（既存のプロジェクトで作成は使いません）。
  3. ボタンをクリックすると、数秒でキーが生成されます。
[スクショ: 「新しいプロジェクトで API キーを作成」ダイアログ。2 択のどちらを選ぶか矢印で示す]
「請求先アカウントを設定してください」と出た場合は設定しないでください。
無料枠のまま使うには請求先アカウントを設定しないことが重要です。このメッセージが出ても「閉じる」または「後で」を選んで先に進めてください。

Step 4 — API キーをコピーする

  1. 画面に長い文字列が表示されます。
    先頭が AIzaSy で始まる、40 文字程度の英数字の羅列が API キーです。
  2. 「コピー」ボタン（クリップボードのアイコン）をクリックしてコピーします。
  3. コピーしたキーは次の Part 5 で使います。メモ帳などに一時保管しておいてください。
[スクショ: 発行された API キー（一部マスク）とコピーボタンの位置]
この API キーは秘密情報です。
他人に見せない・SNS に投稿しない・GitHub などにアップロードしない。
もし漏れてしまった場合は、Part 7 の Q6 を参照してすぐに無効化してください。

Step 4 完了チェックリスト

  • Google AI Studio（aistudio.google.com）にログインできた
  • AIzaSy で始まる API キーを取得した
  • API キーをコピーしてメモ帳に一時保存した
Part 5

GAS の「スクリプトプロパティ」に登録する

取得した API キーを、STRATEGY-KIT が読み取れる場所（スクリプトプロパティ）に保存します。
スクリプトプロパティ（Script Properties）とは、GAS プロジェクト内に安全にデータを保存できる「金庫」のような場所です。コードを共有しても、ここに保存した値は他人に見えません。

Step 1 — GAS プロジェクトを開く

  1. セットアップガイドの Step 2 で作った Apps Script プロジェクトを開きます。
  2. まだ開いていない場合：Google スプレッドシートのメニュー「拡張機能 → Apps Script」から開けます。
[スクショ: Google スプレッドシートのメニューバーで「拡張機能 → Apps Script」を選択した状態]

Step 2 — プロジェクトの設定を開く

  1. Apps Script のエディタが開きます。
  2. 左側のサイドバーにある歯車アイコン「プロジェクトの設定」をクリックします（サイドバーの一番下付近にあります）。
[スクショ: Apps Script 左サイドバーの歯車アイコン「プロジェクトの設定」の位置]

Step 3 — スクリプトプロパティを追加する

  1. 「プロジェクトの設定」画面を下にスクロールして「スクリプト プロパティ」セクションを見つけます。
  2. 「スクリプト プロパティを追加」ボタンをクリックします。
  3. 「プロパティ」の入力欄に GEMINI_API_KEY と入力します。
  4. 「値」の入力欄に Part 4 でコピーした API キー（AIzaSy...）を貼り付けます。
  5. 「スクリプト プロパティを保存」ボタンをクリックします。
[スクショ: 「スクリプト プロパティ」セクションで「GEMINI_API_KEY」を入力した状態]
プロパティ名の綴りは完全一致が必須です。
GEMINI_API_KEY ← この通り、すべて大文字・アンダースコアで区切る。
gemini_api_key（小文字）や GEMINIAPI_KEY（アンダースコアなし）では動きません。
値の前後に不要なスペースが入っていないか確認してください。コピーペーストすると末尾にスペースが紛れることがあります。

Step 4 — 動作確認

  1. スプレッドシートに戻り、STRATEGY-KIT メニュー →「テンプレート原本セットアップ」を実行します（すでに実行済みでも問題ありません）。
  2. STRATEGY-KIT メニュー →「自動化タブを開く」をクリックします（または拡張機能のサイドパネルを開いて「自動化」タブを選択）。
  3. 「接続テスト」ボタンをクリックします。
  4. 「✓ 接続成功（Gemini OK）」 と表示されれば設定完了です。
[スクショ: 拡張機能サイドパネルの「自動化」タブで「✓ 接続成功（Gemini OK）」が表示された状態]

Part 5 完了チェックリスト

  • GAS プロジェクトの「プロジェクトの設定」を開けた
  • スクリプトプロパティに GEMINI_API_KEY（大文字・完全一致）を追加した
  • 値として API キーを貼り付けて保存した
  • 接続テストで「✓ 接続成功（Gemini OK）」を確認した
Part 6

半自動モード／全自動モードの使い方

API キーの登録が完了したら、いよいよ半自動・全自動モードを使えます。
初めての方は必ず半自動から試してください。

推奨

半自動モード

1 フェーズごとに AI の出力を確認してから次に進む。無料枠でも安心して使える。

上級者向け

全自動モード

9〜10 フェーズを連続実行。無料枠の分単位制限に当たる可能性あり。

半自動モードの操作手順

  1. 拡張機能のサイドパネルを開き、「自動化」タブを選択します。
  2. 「使用モデル」が gemini-2.5-flash（デフォルト）になっていることを確認します。
  3. 「開始フェーズ」を選びます。最初は「§0 から」でよいです。途中から再開する場合は該当フェーズを選びます。
  4. 「半自動を開始」ボタンをクリックします。
  5. 1 フェーズ分の処理が完了すると、結果がスプレッドシートに書き込まれ、拡張機能が一時停止します。
  6. AI の出力内容を確認して問題なければ「次のフェーズへ進む」をクリックします。
  7. これを繰り返して全 10 フェーズを完了させます（所要 30〜60 分）。
途中でやめても大丈夫です。進行状況は保存されるので、次回は続きのフェーズから再開できます。

全自動モードについての注意

  1. 手順は半自動と同じですが、最後に「全自動」を選びます。
  2. 9〜10 フェーズが連続で実行されます。
  3. Gemini 無料枠の分単位制限（10 RPM）に当たった場合、途中で止まる可能性があります。
  4. v0.11 ではフェーズ間に 7 秒以上の待機を入れる設定を実装予定です。
全自動が途中で止まっても焦らないでください。
エラーが出た箇所のフェーズ番号を確認し、半自動モードで続きから再開できます。
Part 7

トラブルシュート（FAQ）

困ったときはここを確認してください。

Q1「GEMINI_API_KEY 未設定」と出る
確認すること：
  • スクリプトプロパティのプロパティ名が GEMINI_API_KEY（全大文字・アンダースコア区切り）になっているか
  • 値の前後に余分なスペースが入っていないか
  • 「スクリプト プロパティを保存」ボタンを押して保存を完了させたか
保存後はスプレッドシートのページを一度リロード（F5 キー）してから再試行してください。
Q2「API key not valid. Please pass a valid API key.」と出る
原因：API キーが正しくコピーできていない、またはキーが無効化されています。
対処：
  1. Google AI Studio（aistudio.google.com/app/apikey）を開く
  2. 一覧に表示されているキーの「コピー」ボタンを使って再コピー
  3. スクリプトプロパティの値を貼り直して保存
キーが一覧に表示されていない場合は、「Create API key」から新しく発行してください。
Q3「429 RESOURCE_EXHAUSTED」と出る
原因：Gemini 無料枠の分単位制限（10 RPM）に達しました。
対処：
  • 1 分間待ってから「リトライ」または同じフェーズを再実行
  • 全自動モードを使っている場合は、半自動モードに切り替えて続きから再開
  • 使用モデルを gemini-2.5-flash-lite に変更すると上限が緩くなる（RPM 15）
課金は発生しません。制限に当たって止まるだけです。
Q4全自動モードが途中で止まってしまう
ほとんどの場合、Q3 と同じ原因（分単位制限）です。
推奨対処：
  • 全自動ではなく半自動モードを使う（根本的な解決）
  • どのフェーズで止まったかを確認して、そのフェーズから半自動で再開する
v0.11 でフェーズ間の待機時間設定を実装予定です。
Q5課金されないか不安
クレジットカードを登録していなければ、物理的に課金できません。
Google AI Studio での API キー発行に、クレジットカードの入力画面は一切出ません。
請求先アカウントが存在しない状態では、Google 側のシステムが請求を送ることができない仕組みになっています。

万が一「請求先アカウントを設定してください」というメッセージが出ても、設定せず無視してください。
Q6API キーを誰かに見られてしまった
すぐに以下を実施してください：
  1. Google AI Studio（aistudio.google.com/app/apikey）を開く
  2. 該当するキーの行の「削除」ボタンをクリックして無効化する
  3. 「Create API key」から新しいキーを発行する
  4. GAS のスクリプトプロパティの GEMINI_API_KEY の値を新しいキーで上書き保存する
クレカ未登録であれば金銭的な被害は発生しませんが、無料枠を他人に使われてしまう可能性があります。早めに対処してください。
Q7拡張機能を使わずスプレッドシートで Gemini を使いたい
API キーが登録されたプロジェクトでは、スプレッドシートのセルでカスタム関数 =GEMINI("プロンプト") が使えます。
ただしこの機能は GAS プロジェクトに対応する関数が実装されている場合のみ動作します。
詳しくは講師（山口さん）に確認してください。
Q8Gemini と ChatGPT、どっちを使うべき？
半自動／全自動モードは Gemini API のみ対応しています。
一方、各フェーズには「Claude で開く」「ChatGPT で開く」ボタンがあり、クリックするとそれぞれの AI のブラウザ画面にプロンプトを貼り付けた状態で開きます（API キー不要）。

推奨の使い分け：
  • 自動化したい・時間を節約したい → Gemini API（半自動モード）
  • 出力を細かく調整したい・別の AI と比較したい → 各 AI のブラウザ版ボタンを使う
Q9Google Cloud Platform（GCP）を触ってしまった場合は？
触ること自体は問題ありません。ただし触る必要はありません。
注意が必要なのは以下の場合です：
  • GCP コンソールで「課金を有効にする」「請求先アカウントを作成・接続する」という操作をした場合
  • → 課金の可能性が生まれるため、すぐに「プロジェクトをシャットダウン」するか請求先アカウントの接続を解除してください
GCP のプロジェクトを作成しただけ（課金を有効化していない）なら課金は発生しません。
Q10将来的に課金に切り替えた場合、月いくらかかる？
受講者レベルの使い方であれば、月 数百円〜数千円 が目安です。
具体的な金額は使用量（リクエスト数・トークン数）によって変わります。

参考：gemini-2.5-flash の有料プランは入力トークン 100万あたり $0.15〜$0.60（コンテキスト長による）。
月 100 回の戦略立案（1 回あたり 5 万トークン消費）なら 月 500 万トークン ≒ 月 $0.75〜$3（約 100〜450 円）程度です。
ただし、受講期間中はクレカ登録なし・無料枠での利用を推奨します。
Part 8

セキュリティについて知っておくべきこと

「セキュリティ」という言葉は難しく聞こえますが、要点は 3 つだけです。

API キーは「あなたが Google に料金を払うためのチケット」と同じです。
クレカ未登録でも、漏れると他人が無料枠を使い切ってしまう可能性があります。
API キーの安全な保管場所 GAS のスクリプトプロパティに保存する限り、コードを共有しても他人にキーは見えません。スクリプトプロパティは暗号化されて保存されます。
コードを共有するときの注意 GAS プロジェクトを誰かと共有する場合も、スクリプトプロパティの値は共有されません。安全です。
Web App URL の取り扱い GAS を「ウェブアプリ」として公開した場合、その URL を知っている人は「あなたの代わりに Gemini を呼び出す」ことができます。URL を Slack・LINE などに公開リンクで貼らないようにしてください。
クレカ未登録の場合の金銭リスク クレジットカードを登録していなければ金銭的リスクはゼロです。無料枠を使い切られる可能性はありますが、お金は一切かかりません。

やってはいけないこと・まとめ

やってはいけないこと 理由 やってしまった場合の対処
API キーを SNS・チャットに貼る 第三者が無料枠を使える AI Studio でキーを削除して再発行（Q6 参照）
API キーを GitHub などにアップロード クロールで自動収集されることがある 同上。GitHub は履歴も残るため特に注意
GCP で請求先アカウントを作成・接続する 課金の可能性が生まれる すぐにプロジェクトをシャットダウン
Web App URL を公開リンクで共有 他者があなたの Gemini 枠を使える GAS の Web App を再デプロイしてアクセス権を制限
まとめ：スクリプトプロパティに保存して、キーをコードやチャットに直接書かない。これだけ守れば十分です。
