§8 まで進んだ方向け

計測クイックスタート
——「翌週の数字」を取りに行く

§8 で決めた KPI は、実際に数字が集まって初めて役に立ちます。このガイドは、来週の月曜に「先週はどうだった？」の数字を実際に見られる状態を、最小の手間で作るためのものです。ツールを全部そろえる必要はありません。あなたに関係する取得手段だけ選んでください。

§8-3 とつながる 紙でもOK 無料の範囲で 15分レビュー付き

なぜ「計測」から始めるのか

§8 で作った KPI ツリーは、とても大事なのに、ひとつだけ落とし穴があります。数字が手元に集まらない指標は、どれだけきれいに設計しても動きません。「先週のリーチは？」「今週の新規来店は？」——その数字が取れないと、§9 の週次 PDCA（振り返り）はそこで止まってしまいます。

設計だけでは回らない KPI は「目標の数字」。計測は「今の実際の数字」。両方そろって初めて、差を見て手を打てます。
取れる数字しか使えない 理想の指標より、まず「毎週ちゃんと数えられる指標」を優先します。完璧なデータより、続く記録です。
15分で回せる形に 大がかりな分析基盤は要りません。スプレッドシート1枚と、週15分の振り返りがあれば PDCA は回り始めます。
このガイドのゴールは「GA4 を使いこなす」ことではありません。§8-3 の測定設計テーブルの空欄を埋め、§9 の週次レビューで見る数字を実際に用意することです。ここだけ意識して進めてください。

あなたが使う「取得手段」を選ぶ

数字の取り方（＝取得手段）は、STRATEGY-KIT では次の 5 種類にまとめています。§8-3 の「取得手段」の欄でも、この 5 つの名前から選ぶようになっています。全部やる必要はありません。あなたの事業に関係する 2〜3 個だけで十分です。

取得手段（§8-3 の名前） 向いている数字 こんな事業に このガイドの該当
GA4 Web サイト・予約ページの訪問数、問い合わせ数 ホームページ／予約サイトがある ① GA4 最小設定
SNSインサイト 投稿のリーチ・保存・プロフィール来訪 Instagram・X で集客している ② SNSインサイト
POS・レジ 客数・客単価・売上・再来 店舗でレジ会計がある（飲食・小売・ジム等） ③ POS・レジ／予約台帳・カルテ
予約台帳・カルテ 予約数・来店数・リピート回数 予約制（サロン・整体・教室・クリニック等） ③ POS・レジ／予約台帳・カルテ

このほかに ④ UTM 最小規約という「共通のちょっとした工夫」があります。これは取得手段そのものではなく、GA4 や SNSインサイト で「どこから来たお客さんか（チラシ？SNS？LINE？）」を見分けられるようにするための下ごしらえです。チラシや SNS からサイトに誘導している方だけ、④ も読んでください。

取得手段別セットアップ

関係するものだけ進めてください。どれも「まず 1 個だけ」を目標にしています。最初から完璧を狙わないのがコツです。

1GA4 最小設定オンライン

対応する取得手段：GA4｜ホームページ・予約ページの訪問や問い合わせを数えたい方向け。

GA4（Google アナリティクス 4）は、あなたのサイトに何人来て、何をしたかを無料で記録してくれる Google のサービスです。「初めて聞いた」で大丈夫です。ここでは「①測り始める」「②大事な1件を数える」「③どこで見るか」の 3 つだけやります。

① 測り始める（プロパティを作る）

  1. Google アカウントでログインした状態で analytics.google.com を開きます（§8 まで進んだ方なら、拡張機能で使っている Google アカウントでOK）。
  2. 案内に沿って「測定を開始」→ アカウント名（会社名や屋号でOK）→「プロパティ」の名前（サイト名でOK）を入力します。
  3. 「データストリーム」で「ウェブ」を選び、あなたのサイトの URL を入れると、G- から始まる測定 IDと、貼り付け用のタグ（数行のコード）が表示されます。
  4. そのタグを、サイトの管理画面に貼ります。作り方によって貼る場所が違いますので、下のヒントを見てください。
サイトの種類ごとの貼り方（よくある3パターン）:
  • WordPress: 「Site Kit by Google」などの無料プラグインを入れ、測定 ID を入れるだけ。コードを触らずにつながります。
  • Wix・ペライチ・STUDIO 等の作成サービス: 管理画面の「設定 → マーケティング／アナリティクス連携」に G- の測定 ID を入れる欄があります。
  • 自分で HTML を触れる場合: 表示された貼り付けタグを、各ページの <head> の中に貼ります。
貼る場所が分からないサービスを使っている場合は、「（サービス名） GA4 連携」で検索すると公式手順が見つかります。

② 大事な1件を数える（コンバージョンを1個だけ）

アクセス数だけ見ても打ち手にはつながりません。「これが増えたら売上に近づく」という行動を1つだけ選んで、それを数える設定にします。多くの事業ではこのどれかです。

  • 予約ボタンのクリック／予約完了ページの表示
  • 問い合わせフォームの送信完了
  • 電話番号のタップ（スマホ）
  • LINE 追加ボタンのクリック
  1. GA4 の左メニュー「管理（歯車）」→「イベント」または「キーイベント」を開きます。
  2. 目的の行動（例：予約完了ページの表示）をキーイベント（旧・コンバージョン）として登録します。まずは1個だけで十分です。
設定直後は数字が「0」でも正常です。GA4 はデータの反映に 最大 24〜48 時間かかります。今日設定して今日0でも壊れていません。翌日以降に確認してください。

③ どこで見るか（毎週見る場所）

  1. 左メニュー「レポート」→「エンゲージメント」で、ページごとの表示回数が見られます。
  2. 「集客」→「トラフィック獲得」で、どこから来たか（検索・SNS・直接）が分かります。④ の UTM を設定すると、ここでチラシや LINE も見分けられます。
  3. 設定したキーイベントの回数が、あなたが毎週見る一番大事な数字です。これを後述のダッシュボードに転記します。
ここまでで OK: 測定 ID をサイトに貼れて、キーイベントが1個登録できていれば、GA4 の最小設定は完了です。翌週から「訪問数」と「キーイベント数」が取れます。

2SNSインサイトオンライン

対応する取得手段：SNSインサイト｜Instagram・X で集客している方向け。アプリの中だけで完結します。

「インサイト」は、SNS アプリが無料で見せてくれる投稿やアカウントの成績表です。特別な連携は不要で、アプリの画面を見るだけです。ただし Instagram は「プロアカウント」への切り替えが必要な点だけ注意してください。

Instagram の場合

  1. プロフィール右上のメニュー →「設定とプライバシー」→「アカウントの種類とツール」→「プロアカウントに切り替える」（無料）。ビジネスまたはクリエイターを選びます。
  2. 切り替え後、各投稿の下に「インサイトを見る」が出ます。ここでリーチ（見られた人数）・保存数・プロフィールへのアクセスが分かります。
  3. アカウント全体の数字は、プロフィール画面の「プロフェッショナルダッシュボード」から。過去7日／30日のリーチやフォロワー増減が見られます。

X（旧Twitter）の場合

  1. 各ポストの下に表示される「アナリティクスを表示」（棒グラフのアイコン）で、インプレッション・エンゲージメント・プロフィールアクセスが見られます。
  2. アカウント全体は、メニューの「アナリティクス」（PC・プレミアム等で利用範囲が変わります）から確認します。
毎週見る数字は「リーチ（インプレッション）」と「プロフィールアクセス」の2つで十分です。全部の数字を追う必要はありません。§8-2 の KPI（例：リーチ→プロフィール来訪→フォロー）の一番上の数字として、毎週ダッシュボードに転記します。
インサイトの数字は時間が経つと古い投稿ぶんが見づらくなることがあります。毎週決まった曜日に「先週ぶん」をメモしておくのが確実です（後述の週15分レビューでまとめて記録します）。
ここまでで OK: Instagram はプロアカウントに切り替わっていて、投稿インサイトが見られる。X はポストのアナリティクスが開ける。これで毎週の SNS 数字が取れます。

3POS・レジ／予約台帳・カルテオフライン

対応する取得手段：POS・レジ・予約台帳・カルテ｜店舗・予約制の事業向け。紙でも成立します。

売上・客数・再来といったオフラインの数字は、じつは一番大事な KGI（最終目標の数字）につながります。ネットの数字が無くても、ここが取れていれば PDCA は回せます。高価な POS レジは不要です。手書きの記録で十分です。

すでにレジ・予約システムがある場合

  • 多くの POS（Airレジ・Square・スマレジ等）や予約システムには「日次／週次の売上・客数レポート」があります。まずはその画面を開けるようにするだけでOK。
  • 毎週、週合計の客数・売上・（分かれば）新規／再来の内訳をダッシュボードに転記します。

紙・手書きで始める場合（記録テンプレ）

レジや予約システムが無くても、次の「正の字カウント」だけで始められます。1日1枚、レジ横やカウンターに置いてください。

日付 来店・予約数（正の字） うち新規（初来店） 売上合計 ひとことメモ（天気・イベント等）
7/7（月） 正 正 一（＝11） 正（＝5） 48,000 雨・チラシ配布日
7/8（火）        
「新規かどうか」を聞くのが難しいときは、会計時に「初めてのご来店ですか？」と一言添えるだけでOK。§8-1 の KGI が「再来率」の方は、この新規／再来の内訳がそのまま必要な数字になります。
紙の記録は週に1回、必ずスプレッドシートに合計を打ち込んでください。紙のままだと週をまたいで比較できません。「毎週月曜に先週ぶんを入力」を習慣にすると続きます。
ここまでで OK: レジレポートを開けるか、紙テンプレで日々の客数・売上・新規を数えられる。週合計をスプレッドシートに移せる。これでオフラインの数字が取れます。

4UTM 最小規約（任意）オンライン

下ごしらえのテク｜チラシ・SNS・LINE などからサイトへ誘導している方向け。①②を「どこから来たか」で分けられます。

UTM とは、リンクの末尾に「これはチラシ経由のリンクですよ」という目印を付ける仕組みです。この目印を付けておくと、GA4 の「集客」レポートでチラシ・SNS・LINE を別々に数えられるようになります。難しく考えず、3種類だけ決めれば十分です。

最小ルール：この3つだけ決める

リンクの後ろに ?utm_source=●●&utm_medium=▲▲ を付けます。source（どこから）だけ使い分ければ実用上は足ります。

流入元 リンクの末尾に付ける目印 使う場面
チラシ・紙 ?utm_source=flyer&utm_medium=print チラシの QR コードの行き先 URL に付ける
SNS（プロフィールのリンク） ?utm_source=instagram&utm_medium=sns Instagram・X のプロフィール URL に付ける
LINE ?utm_source=line&utm_medium=message LINE 配信メッセージ内のリンクに付ける
目印付きのリンクは、Google の「Campaign URL Builder」に元 URL と上記の値を入れると自動で作れます。手打ちでミスしがちな記号（? と &）を間違えずに済みます。作ったチラシ用の長い URL は、無料の QR コード作成サービスで QR にすると配布しやすくなります。
UTM は「どこから来たか」を分けたい人だけの任意ステップです。まだ Web 誘導をしていない、または流入元を分ける必要がなければ、飛ばして構いません。
ここまでで OK: チラシ・SNS・LINE の3種に目印付きリンクを用意できれば完了。GA4 の「集客 → トラフィック獲得」で、それぞれ別の行として数えられるようになります。

5アンケート・現場ヒアリングオフライン

対応する取得手段：アンケート・現場ヒアリング｜「何を見て来たか」は、これでしか取れません。全事業におすすめ。

GA4 も SNS も「ネットの中の動き」しか分かりません。でも実際のお客さんは「チラシを見て」「友達に聞いて」「たまたま通りかかって」来ています。この来店きっかけ（認知経路）は、直接聞くのが一番正確です。難しいアンケート用紙は不要です。

いちばん簡単なやり方：会計時にひとこと

  1. 会計や予約受付のとき、「失礼ですが、何で当店をお知りになりましたか？」と一言聞きます。
  2. スタッフが手元の「正の字シート」に、選択肢ごとにチェックを入れるだけ。お客さんに書いてもらう必要はありません。
来店きっかけ 今週のカウント（正の字）
Instagram / X などの SNS正 正（＝10）
チラシ・ポスティング正 一（＝6）
紹介・口コミ（知人）正（＝5）
通りがかり・看板三（＝3）
その他（検索・食べログ等） 
QR コードで無料の Google フォームにしてもOKですが、最初は紙の正の字が最も回収率が高いです（お客さんの手を止めないため）。集計だけ週次でスプレッドシートに入れれば、SNS やチラシの「本当の効き目」が見えてきます。
ここまでで OK: 来店きっかけを聞く一言と、選択肢の正の字シートを用意できれば完了。オンラインの数字だけでは分からない「本当の流入元」が毎週取れます。

KPI ダッシュボード雛形（Google スプレッドシート）

取れるようになった数字を1 枚のスプレッドシートに集約します。むずかしい関数は要りません。シートを 2 枚だけ作ってください。1枚目は §8-3 の測定設計テーブルをそのまま写すための表、2枚目は毎週の実測値を書き足していく表です。

シート1「測定設計」（§8-3 をそのまま転記）

§8-3 で作った測定設計テーブルの中身を、この列にそのまま写します。列名を1行目に入れておくと、あとから見返しやすくなります。

この「週次記録」シートが、次の週15分レビューと §9 の週次 PDCAで毎週見る画面になります。数字を横に並べておくと、前の週と比べて増えた・減ったが一目で分かります。グラフは慣れてからで十分です。
数字が取れなかった週は、空欄のままにせず「未計測」と書いてください。「0（ゼロだった）」と「未計測（測れなかった）」はまったく意味が違います。ここを混ぜると、あとで振り返るときに誤解のもとになります。

週次15分レビュー会テンプレ

計測がそろったら、週に1回・15分だけ数字を見る時間を作ります。これが §9 の週次 PDCA の「Check（見て・なぜかを考える）→ Act（次の手を決める）」そのものです。ひとりでも、スタッフとでもOK。曜日と時間を固定するのが続けるコツです（例：毎週月曜の朝9時）。

進行台本（15分）

  • 事前 1分数字を埋める
    GA4・SNS インサイト・レジ／台帳から先週ぶんの数字を、ダッシュボードの「週次記録」に転記しておく（レビュー直前でOK）。
  • 00:00–03:00見る（先週どうだった？）
    各指標を「シート1」の目標値・しきい値と見比べる。○（達成）／△（あと少し）／×（しきい値割れ）を口に出すだけ。§9 の Plan・Do の結果確認にあたります。
  • 03:00–08:00なぜ？（要因を1行で）
    ×や大きく動いた指標について「なぜこの数字になったか」の仮説を最低1行、気づき欄に書く。例：「チラシ配布週だから新規が増えた」。これが §9-1 の Check「要因分析仮説欄」です。正解でなくてよい、仮説でOK。
  • 08:00–13:00どうする？（しきい値で判断）
    §8 で決めたしきい値と照らして、あらかじめ決めた対応を実行するか判断する。例：「リーチが前週比 −20% を割った → 今週は投稿頻度を増やす」。感覚ではなく数字で決めるのが §9 の Act のルールです。
  • 13:00–15:00次の1手を決めて記録
    「今週やること」を1つだけ決め、担当と、次回見る数字をメモする。§9-5 の改善ログ（試したこと・結果・学び・次アクション）の1行になります。
§9 では、この週次レビューの中でマスタードキュメントの [仮説] 行も毎週最低3件取り上げ、「昇格／継続／削除」を判定します（§9-3 採否判断ルーチン）。計測がそろっていると、この判定に使う実測値が手元にある状態になります。まずは数字を見る習慣を15分で固定するところから始めてください。
レビューを長くしすぎないこと。15分で終わらないときは、見る指標が多すぎるサインです。§8-2 のとおり、KPI は施策1本につき1〜2個まで。まず3指標くらいに絞ると、毎週続けられます。

よくある詰まり（FAQ）

Q1数字が取れない週があった。どうすれば？
空欄のままにせず「未計測」と書いてください。測り忘れた週があっても PDCA は止まりません。翌週からまた記録すればOKです。大事なのは「0（実際にゼロ）」と「未計測（測れなかった）」を分けて書くことです。
Q2GA4 を設定したのに数字が「0」のまま
設定直後は正常です。GA4 はデータ反映に最大 24〜48 時間かかります。まず「レポート → リアルタイム」で、自分でサイトを開いたときに1が立つか確認してください。リアルタイムにも出ない場合は、測定 ID の貼り付け場所が違う可能性があります（①の「サイトの種類ごとの貼り方」を再確認）。
Q3Instagram のインサイトが見当たらない
個人アカウントのままだと表示されません。「設定 → アカウントの種類とツール → プロアカウントに切り替える」（無料）を行ってください。切り替え後、しばらくすると過去の投稿にもインサイトが表示されるようになります。
Q4何を測ればいいか分からない・指標が多すぎる
§8-3 の測定設計テーブルで決めた指標だけを測ってください。それ以上は増やさないのが正解です。迷ったら「§8-1 の KGI に一番近い数字（売上・新規・再来など）」1つと、「その手前の数字（リーチ・訪問など）」1つの、合計2〜3個から始めます。
Q5レジも予約システムも無い。数字が取れない
紙で十分です。③の「正の字カウント」テンプレをレジ横に置き、日々の客数・新規・売上を数えてください。予約台帳・カルテがある業種は、そこから週合計を数えればOK。手書きでも、毎週スプレッドシートに合計を入れれば立派な計測です。
Q6毎週の記録が続かない
原因はたいてい「測る指標が多い」か「時間が決まっていない」のどちらかです。指標を3つまでに絞り、曜日と時間を固定（例：毎週月曜9時）してください。1回15分の週次レビューの中で記録もまとめて行うと、別作業になりません。
Q7有料ツールや API キーは必要？
不要です。このガイドは GA4・SNS インサイト・Google スプレッドシート・紙という無料の範囲で完結します。有料の分析ツールや API キーは、必要になってから検討すれば十分です（STRATEGY-KIT の Gemini 設定とは別の話で、計測には要りません）。

これで準備完了です

あなたに関係する取得手段を設定し、ダッシュボードのシートを2枚作り、週15分のレビュー時間を決めたら、計測の準備は完了です。翌週の月曜には、実際の数字を見ながら §9 の PDCA を回し始められます。
