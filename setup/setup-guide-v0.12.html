セットアップを始める前に

以下が揃っているか確認してください。特に テストユーザー登録（下記）が済んでいないと STEP 2 で必ず止まります。

Google アカウント 個人の Gmail アドレスで OK。Workspace アカウントでも使えます。

いちばん大事な事前準備：テストユーザー登録
STRATEGY-KIT は現在「テスト中のアプリ」として運用しています。連携できる Google アカウントは、講師（山口さん）側にあらかじめ登録されたテストユーザーだけです。
使う予定の Gmail アドレスを、事前に講師へ伝えて登録してもらってください。 未登録のまま STEP 2 に進むと、連携の途中で「アクセスをブロック（access_denied）」と表示されて先に進めません。その場合は自分では解決できないので、登録済みか講師に確認してください。
ZIP は解凍してから使います。 ダウンロードしたままの ZIP ファイルを Chrome に読み込んでも動きません。必ずデスクトップや「ダウンロード」フォルダに解凍（展開）してから STEP 1 に進んでください。
1

拡張機能を Chrome に読み込む

パッケージ化されていない拡張機能（Unpacked）として入れる
Chrome 拡張機能
現在 Chrome Web Store への申請中のため、ストアからではなく手動で読み込みます（Unpacked 方式）。通常のインストールより手数が多いだけで、難しくはありません。

操作手順

  1. ZIP を解凍します。 ダウンロードした ZIP ファイルをダブルクリックして解凍します（Mac は自動展開、Windows はファイルを右クリック →「すべて展開」）。同じ名前のフォルダが作られます。
  2. Chrome で新しいタブを開き、アドレスバーに次を入力して Enter を押します。
Chrome アドレスバーに入力 
chrome://extensions/
  1. 拡張機能の管理ページが開きます。画面右上の「デベロッパーモード」のトグルをオン（青色）にします。
  2. 画面左上に「パッケージ化されていない拡張機能を読み込む」ボタンが出ます。これをクリックします。
  3. ファイル選択ダイアログで、STEP 1-1 で解凍したフォルダ自体を選び「開く」（Mac は「選択」）をクリックします。フォルダの中に入らず、フォルダを選択してください。
  4. 拡張機能一覧に「STRATEGY-KIT Helper」が追加されれば成功です。
Chrome 起動時に「デベロッパーモードの拡張機能を無効にしますか？」というポップアップが出ることがあります。
これは Chrome の仕様です。「×」で閉じる（キャンセル）を選んでください。「無効にする」を押すと拡張が止まります。毎回出る場合は、起動のたびに × で閉じてください。

よくある詰まりポイント

「パッケージ化されていない拡張機能を読み込む」ボタンが見当たらない
デベロッパーモードがオフになっています。画面右上のトグルを確認してオンにしてください。
フォルダを選んだのにエラーになる
ZIP を解凍したフォルダではなく、ZIP ファイルそのものを選んでいる可能性があります。解凍後のフォルダを選んでください。フォルダの中に manifest.json というファイルがあれば正しいフォルダです。
完了の確認: chrome://extensions/ の一覧に「STRATEGY-KIT Helper」が表示され、エラーなく有効になっていれば STEP 1 完了です。
2

Google アカウントを連携する

拡張機能があなたの Google ドキュメントに保存できるようにする
サイドパネル 設定ページ Google 連携
このツールは、作った戦略をあなたの Google ドキュメントに記録します。そのために一度だけ「あなたの Google アカウントを使う許可」を出す作業がこの STEP です。最初の関門はここだけなので、落ち着いて進めてください。

操作手順

  1. Chrome の右上、パズルピースのアイコン（拡張機能メニュー）をクリックし、一覧の「STRATEGY-KIT Helper」の横にあるピンのアイコンを押してツールバーに固定しておくと便利です（任意）。
  2. ツールバーの STRATEGY-KIT のアイコンをクリックします。画面の右側に「サイドパネル」が開きます。
  3. サイドパネルの上部に「はじめに · 3 ステップ」という帯があり、「Google 連携」「事業情報」「§0 を始める」の 3 つが並んでいます。この一番左の「Google 連携」をクリックします。
  4. 新しいタブで設定ページが開きます。「Google アカウント連携」の欄にある「連携 / 再連携」ボタンをクリックします。
  5. Google のログイン画面が出たら、テストユーザー登録した Gmail アドレス（事前準備で講師に伝えたもの）でログインします。
  6. 「このアプリが Google アカウントへのアクセスを求めています」という同意画面で、内容を確認して「許可」（続行）まで進めます。
  7. 設定ページに戻り、「状態確認」ボタンを押して「連携済み」の表示になれば成功です。
「アクセスをブロック（access_denied）」と出て進めないとき
使っている Gmail アドレスが、まだテストユーザーに登録されていません。これは自分の操作では直せません。そのアドレスを講師（山口さん）に伝えて、テストユーザー登録を依頼してください。 登録後に、もう一度「連携 / 再連携」から試すと通ります。
連携は約 7 日で切れます（重要）
テスト中のアプリのため、一度連携してもおよそ 7 日で許可が自動で失効します。週をまたぐと、自動化などが「未連携」の表示になって止まることがあります。「未連携」と出たら壊れたわけではありません。 設定ページの「連携 / 再連携」をもう一度押せば、また使えるようになります。定期的に押し直す前提でお使いください。
「このアプリは Google で確認されていません」と表示されたとき
テスト中のアプリでは、この警告が出ることがあります。あやしいものではありません。画面下部の「詳細」→「（アプリ名）に移動（安全ではないページ）」をクリックし、そのまま「許可」まで進めてください。

よくある詰まりポイント

アイコンを押してもサイドパネルが開かない
chrome://extensions/ で STRATEGY-KIT Helper が「有効」になっているか確認してください。有効なのに開かない場合は、いったん Chrome を再起動してから、もう一度アイコンをクリックしてみてください。
「連携 / 再連携」を押しても何も起きない
ポップアップがブロックされている場合があります。アドレスバー右端のブロック通知を確認して許可するか、少し待ってからもう一度押してください。
完了の確認: 設定ページの「Google アカウント連携」で「状態確認」を押し、「連携済み」と表示されれば STEP 2 完了です。
3

事業情報を入力する

業種と店舗名を入れて、プロンプトに自動で反映させる
設定ページ
ここで入れた業種・店舗名は、各フェーズのプロンプト（AI への指示文）に自動で差し込まれます。テスト目的なら仮の内容でも構いません。

操作手順

  1. STEP 2 で開いた設定ページの上部にある「事業情報」の欄を使います（サイドパネルの帯から「事業情報」を押しても同じ設定ページが開きます）。
  2. 「業種プリセット」で、近いものを選びます。ぴったりが無ければ「その他」を選び、次の欄で書きます。
  3. 「業種（自由入力）」に具体的な業種を入れます（例:「クライミングジム」）。
  4. 「店舗・屋号」にお店や事業の名前を入れます（例:「エナジー柏店」）。
  5. ページ下部の「保存」ボタンを押します。「保存しました」と表示されれば OK です。
完了の確認: 業種と店舗・屋号を入力して「保存」できていれば STEP 3 完了です。
4

マスタードキュメントを作る

戦略を書き込む Google ドキュメントをワンボタンで生成する
設定ページ Google ドキュメント
「マスタードキュメント」は、§0〜§9 の成果を章ごとに記録していく 1 本の Google ドキュメントです。テンプレートを自分で取り込む必要はありません。 ボタン一つで、拡張機能が中身を組み立てた Doc を作ってくれます。

操作手順

  1. 設定ページの「マスタードキュメント」の欄を開きます。
  2. 「新規作成」ボタンをクリックします。少し待つと、あなたの Google ドライブに新しい Google ドキュメントが作られます。
  3. 「📄 開く」ボタンで、作られたマスタードキュメントを確認できます。章立て（§0〜§9）が入った Doc が開けば成功です。
すでに作った Doc を使いたいときは: 「Google Docs URL」欄にその URL を貼り、「確認して保存」を押すと、その Doc を記録先として登録できます。
AI の出力を直接このマスターに書き込まないでください。 AI が生成した文章はいったん別の場所に残し、人間が選んでから転記する運用にしてください（設定ページ「このツールについて」にも同じ注意があります）。
完了の確認: 「📄 開く」で、章立ての入ったマスタードキュメントが開ければ STEP 4 完了です。
5

Gemini API キーを設定する（任意）

AI に文章を自動で書かせたいときだけ必要
設定ページ Gemini
自分で AI チャット（Gemini・ChatGPT など）にプロンプトを貼って進める「手動運用」だけなら、この STEP はスキップして構いません。「全自動生成」や「図解の自動生成」を使うときだけ、Gemini の API キーが要ります。

① まず API キーを取得する

📘 初めての方は完全ガイドを推奨
「API って何？」「Google AI Studio って何？」からゼロで理解できる詳細ガイドを用意しています。キーの取り方はこちらに沿って進めてください。
Gemini API 完全ガイドを開く

かんたんに言うと、Google AI Studio（aistudio.google.com/app/apikey）を開いて「API キーを作成」を押すと、AIza… で始まるキーが発行されます。これをコピーしておきます。

API キーはパスワードと同じ扱いです。 他人に教えたり、SNS・GitHub などに貼ったりしないでください。

② 拡張機能にキーを登録する

設定ページの「Gemini 設定」の欄で登録します。方法は 2 つあり、学習用途では「セキュア学習モード」を推奨します。

おすすめ：セキュア学習モード
キーを拡張機能（この端末）に保存せず、あなた専用の保管場所（Apps Script）に預ける方式です。手順は次のとおりです。
  1. 「Gemini proxy を作成」を押します（初回に Apps Script 側の承認を求められることがあります。表示に従って許可してください）。
  2. キー入力欄に、①で取得した AIza… のキーを貼り付けます。
  3. 「proxy に key を設定」を押します。
  4. 「proxy 実行確認」を押して、正常に動けば完了です。
もう一つ：直接 API key モード
キーをこの端末に保存する簡易な方式です。使う場合は「上限を絞った学習用の無料枠キー」だけにしてください。確認のチェックを入れ、キーを貼り付けて「直接 key を保存」→「直接 key 実行確認」の順に押します。
無料枠について
Gemini の無料枠は、おおよそ1 分あたり 10 回・1 日 250 回までです。手動・半自動なら問題ありませんが、全自動で連続実行すると 1 分あたりの制限に当たることがあります。その場合はフェーズの間に少し時間を空けてください。クレジットカードを登録していなければ課金は発生しません。
完了の確認: 「proxy 実行確認」または「直接 key 実行確認」が成功すれば STEP 5 完了です。手動運用のみの方はスキップで問題ありません。
6

§0 を始めて、最初のアウトプットを出す

フェーズを 1 つ動かして、マスターに記録されるのを確認する
サイドパネル フェーズ

操作手順

  1. 設定ページを閉じ、サイドパネルに戻ります（設定ページ左上の「← サイドパネルに戻る」でも戻れます）。
  2. サイドパネルのタブから「フェーズ（手動で進める）」を開きます。「§0」から順に並んでいます。
  3. 「§0 プレリサーチ（ヒアリング前調査）」を開き、表示されるプロンプトを、対応する AI チャットに送って進めます。全自動を使う場合は「自動化（AIにまとめて任せる）」タブから実行できます。
  4. 出てきた結果を確認し、必要な部分をマスタードキュメントの該当章に記録します（人間が選んで転記します）。
サイドパネルには「フェーズ」「自動化」「リサーチ」「スライド」の 4 つのタブがあります。まずは「フェーズ」で §0 を 1 つ動かし、マスターに記録されることを確認できれば、全体の流れがつかめます。
これでセットアップは完了です。 §0 の結果がマスタードキュメントに記録できれば、あとは §1 → §9 まで同じ要領で進めていけます。

X-KIT / INSTAGRAM-KIT をお使いの方へ

X（旧Twitter）運用の X-KIT と、Instagram 運用の INSTAGRAM-KIT も、セットアップの手順はこのガイドとまったく同じです（拡張機能を読み込む → Google 連携 → 事業情報 → マスタードキュメント作成 → Gemini 設定 → §0 を始める）。違うのは次の点だけです。

  • 拡張機能一覧に表示される名前が「X-KIT」または「INSTAGRAM-KIT」になります（STRATEGY-KIT Helper ではありません）。
  • 読み込む ZIP は、それぞれの製品の ZIP です（X-KIT は x-kit-v0.12.23.zip、INSTAGRAM-KIT は instagram-kit-v0.12.23.zip）。
  • 事業情報や各フェーズの中身が、マーケ戦略ではなく SNS アカウント運用の内容になります。

フェーズの中身（§0〜§9）

§0 プラットフォーム調査 → §1 ヒアリング（運用目的・体制・既存資産・トンマナ）→ §2 競合アカウント／オーディエンス分析 → §3 統合（アカウントの勝ち筋を 1 行で定義）→ §4 ペルソナ・コンテンツピラー・フォロワージャーニー → §5 アカウントコンセプト・bio／固定ポスト設計・トンマナガイド → §6 投稿企画のブレスト（5 枠＋優先度）→ §7 投稿カレンダー・運用エコノミクス → §8 KPI ツリー → §9 PDCA・採否判断。
つまり「マーケティング戦略」を「SNS アカウント運用計画」に読み替えた 10 フェーズになります。進め方（連携・記録・転記のルール）は STRATEGY-KIT と共通です。

連携まわりの注意（テストユーザー登録・約 7 日で失効）は 3 製品すべて共通です。 STEP 2 の説明をそのまま参照してください。

困ったら（よくある質問）

Q1連携で「アクセスをブロック（access_denied）」と出る
使っている Gmail アドレスがテストユーザーに未登録です。自分では直せないので、そのアドレスを講師（山口さん）に伝えて登録してもらってください。登録後、設定ページの「連携 / 再連携」からやり直すと通ります。
Q2しばらく使っていたら「未連携」になって自動化が止まった
故障ではありません。テスト中アプリの許可はおよそ 7 日で自動的に切れます。設定ページの「Google アカウント連携」で「連携 / 再連携」をもう一度押すと復活します。週明けなどに止まっていたら、まずここを試してください。
Q3「このアプリは Google で確認されていません」と出る
テスト中アプリのため出る警告で、正常です。画面下部の「詳細」→「（アプリ名）に移動（安全ではないページ）」→「許可」の順に進めてください。「キャンセル」や「戻る」を押すと連携が完了しません。
Q4拡張機能アイコンを押してもサイドパネルが開かない
chrome://extensions/ で拡張が「有効」になっているか確認してください。「デベロッパーモードの拡張機能を無効にしますか？」で「無効にする」を押してしまった場合は、ここで再度有効化できます。それでも開かない場合は Chrome を再起動してください。
Q5全自動モードが途中で止まる
Gemini 無料枠の「1 分あたり 10 回」の制限に当たっている可能性があります。フェーズとフェーズの間に少し時間を空けてから再実行するか、手動・半自動で 1 つずつ進めてください。
Q6以前のガイド（v0.11）と手順が全然違う
v0.11 までは Apps Script のライブラリ登録や Web App のデプロイが必要でしたが、現行の v0.12 ではその作業は不要になりました。Google 連携（STEP 2）だけで動きます。このガイド（v0.12）に沿って進めてください。

次のステップ：§8 まで進んだら「計測」を始める

セットアップが終わって §0〜§9 を進め、§8 で KPI を設計したら、その数字を実際に取りに行く番です。GA4・SNS インサイト・レジ／台帳・アンケートといった取得手段別のセットアップから、KPI ダッシュボード雛形・週15分レビューまでを、無料の範囲・紙でもOKの形でまとめた「計測クイックスタート」を用意しています。
