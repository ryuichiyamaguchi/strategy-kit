STRATEGY-KIT v0.11 配布物

マーケティング戦略立案AI支援ツールのメジャーアップデート版。Apps Script ライブラリ化により受講者は1回 shim を貼るだけで以降のアップデートは自動反映されます。

受講生向け Chrome 拡張 B2C/B2B 分岐 要点版運用 ICE 予算配分 ライブラリ自動更新

v0.9.x からの主要変更点

  • Apps Script ライブラリ化— 受講者は薄い shim（110行）を1回貼るだけ。ロジック更新は山口さん側のライブラリで行われ自動反映
  • マスタードキュメント = テンプレート Doc コピー方式（v3.0 雛形を Drive で makeCopy）— 見た目・テーブル・段落間隔が完全に揃う
  • §N 要点版（500字以内）を全章に新設— 後続フェーズへの貼付はこれのみ。「★貼付★」のフルテキスト肥大化問題を根絶
  • B2C / B2B 分岐— §1 ヒアリング／§4 STP／§7 ユニットエコノミクス／§8 KGI で業種タイプ別ガイド
  • 新規4セクション— §1-5 自己申告データ確度／§4-5 カスタマージャーニー／§7-6 競合リアクション分析／§7-7 予算ポートフォリオ（ICE スコア）
  • phase-5 を3プロンプト分割— USP→4P/4C→コンセプト＋キャッチコピーの「往復運動」を強制
  • 数字3層化＋レンジ表示標準化— CAC/LTV/Payback は「8,000-14,000円」のようなレンジで提示
  • [事実]タグ3段階化— 一次／複数／仮説／要確認／却下
  • セキュリティ強化（任意）— Web App デプロイは「全員」のままだが、API トークン（合言葉）認証を任意で導入可能に。設定すれば URL が漏れても他人がアクセスできなくなる（STEP 8 参照）

セットアップ手順

所要時間 30〜45 分。一度設定すれば以降は何もしなくて済みます。下は概要版。スクショ・トラブルシューティング付きの完全版は次のリンクから。

📖 完全版セットアップガイドを開く

STEP 1：マスター雛形を Google Docs に取り込む

  1. template_v3.0.md を上記からダウンロード
  2. docs.google.com で空白の Google ドキュメントを新規作成
  3. メニュー「ファイル → 開く」→ ダイアログ上部の「アップロード」タブ → template_v3.0.md をドラッグ＆ドロップ（自動で Google Docs に変換されて新タブで開きます）
  4. 左上のタイトルを「テンプレート原本」などに変更し、URL をメモ（書き換えないこと）

STEP 2：Apps Script で shim を準備

  1. STEP 1 で作ったテンプレート原本 Doc とは別の新規 Google Doc を作成（作業用）
  2. 「拡張機能 → Apps Script」を開く
  3. 左サイドバー「ライブラリ」横の「＋」で StrategyKitLib スクリプトID（山口さんから配布）を入力 → 識別子は StrategyKitLib、バージョンは HEAD（開発モード）
  4. 左サイドバー「ファイル」の Code.gs を全選択して、strategy-kit-v0.11.3-gas-shim 内の Code.gs の中身で置き換え
  5. 保存（Cmd/Ctrl + S）

STEP 3：ウェブアプリとしてデプロイ

  1. 右上「デプロイ → 新しいデプロイ」
  2. 種類選択 →「ウェブアプリ」
  3. 説明: STRATEGY-KIT v0.11
  4. 次のユーザーとして実行: 自分
  5. アクセスできるユーザー: 全員（Chrome 拡張からの fetch は「Google アカウント全員」設定だとログインリダイレクトに飛ばされて通らないため、ここは「全員」が必要です。代わりに STEP 8 のトークン認証で安全性を確保します）
  6. デプロイ → 権限承認（後述の警告に注意）
  7. 表示された ウェブアプリ URL を控える
⚠️ 「Google で確認されていません」警告について
受講者自身がデプロイした自作アプリのため、初回承認時に警告が表示されます。これは正常です：
「詳細」→「(自分のアカウント名)に移動（安全ではないページ）」をクリック → 権限承認を最後まで通します。

STEP 4：Chrome 拡張機能を読み込む

  1. 拡張機能 ZIP をダウンロード → 解凍
  2. Chrome で chrome://extensions/ を開く
  3. 右上「デベロッパーモード」を ON
  4. 左上「パッケージ化されていない拡張機能を読み込む」をクリック
  5. 解凍したフォルダ（strategy-kit-v0.11.3/）を選択
  6. 拡張機能アイコンが追加されたら成功

STEP 5：拡張機能のオプションに GAS URL を登録

  1. 拡張アイコンを右クリック → 「オプション」
  2. 「GAS Web App URL」欄に STEP 3 で得た URL を貼り付け
  3. 「保存」

STEP 6：テンプレート原本を登録（初回のみ）

  1. STEP 2 で作った作業用 Doc を再読込（必須・タブを閉じて開き直す）
  2. メニューバーに「STRATEGY-KIT」が表示されることを確認
  3. 「STRATEGY-KIT → テンプレート原本セットアップ（初回のみ）」を実行
  4. STEP 1 で作ったテンプレート原本 Doc の URL を入力
⚠️ テンプレート原本 Doc では他のメニューを実行しないでください。新規案件は必ず「新規マスタードキュメント作成」から行います。

STEP 7：新規案件を作って動作確認

  1. 「STRATEGY-KIT → 新規マスタードキュメント作成 → 業種を選択」
  2. 店舗名・案件メタ情報を入力
  3. 新規 Doc が自動生成され、テンプレート原本がコピーされた状態になります
  4. これがあなたの戦略マスター文書です

STEP 8：API トークンで鍵を掛ける（任意・推奨）

STEP 3 の Web App アクセス権を「全員」にしたので、URL を知っている人なら誰でもアクセスできる状態です。合言葉（API トークン）を設定すると、URL が漏れても他人がアクセスできなくなります。受講者数十名の限定配布で実害は低いのでスキップしても OK ですが、Slack/LINE で URL 共有してしまった経験がある方は推奨。

  1. 合言葉を決める（20 文字以上のランダムな文字列推奨。例: nrg-2026-spring-7x9k）
  2. STEP 2 の Apps Script エディタを開く →「プロジェクトの設定」（歯車アイコン）→「スクリプト プロパティ」へ
  3. 「スクリプト プロパティを追加」→ プロパティ名 SK_API_TOKEN、値に手順 1 の合言葉 →「保存」
  4. Chrome の拡張機能アイコンを右クリック →「オプション」→「API トークン（任意）」欄に同じ合言葉を入力 →「接続テスト」
⚠️ 合言葉は他人と共有しないでください。パスワードと同じ扱いです。忘れた／無効化したい時は GAS 側のスクリプトプロパティから SK_API_TOKEN を削除（拡張機能側の入力欄も空にする）すれば認証なしの動作に戻ります。

Gemini API キー登録（任意・全自動／半自動を使う場合）

「API って何？」「Google AI Studio と Google Cloud の違いは？」「無料で使える？」など、初めての方の疑問を全部解説した詳しい手順書を用意しました。

📘 Gemini API 完全ガイドを開く（IT 用語ゼロから理解）

— 急ぎの方向けの簡略版手順 —

  1. Google AI Studio で API キーを取得 → aistudio.google.com/app/apikey
  2. Apps Script プロジェクト → プロジェクト設定（歯車アイコン）→「スクリプト プロパティ」
  3. 「スクリプト プロパティを追加」→ プロパティ GEMINI_API_KEY、値に取得したキー
  4. 保存
無料枠の制限: Gemini-2.5-flash は分あたり10リクエスト・1日250リクエスト。半自動モードは問題なく動作しますが、全自動モードは連続実行で分あたり制限に引っかかる可能性があります（フェーズ間に7秒以上の待機が必要）。クレジットカード未登録なら絶対に課金されません。

v0.9.x との併存

すでに v0.9.x で運用中の案件があれば、v0.11 と並行運用できます：

  • Chrome 拡張機能: 別 ID として両方インストール可能（STRATEGY-KIT Helper vs 旧 STRATEGY-KIT Helper v0.10 等）
  • chrome.storage キー: v0.11 は gasWebAppUrl_v10、旧 v0.9.x は gasWebAppUrl で分離
  • GAS: 別 Doc にバインドした別プロジェクトとして併存（同一プロジェクトに両 Code.gs を貼ると関数衝突）
  • 旧 strategy-kit-v0.9.x 受講者の運用中案件はそのまま継続可能
