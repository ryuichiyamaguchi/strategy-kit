セットアップの流れ（概要）

所要 15〜25 分。むずかしいのは「Google 連携（STEP 2）」だけで、あとは数分で終わります。スクショ・トラブル対処付きの完全版は上のガイドから。

STEP 1：拡張機能を Chrome に読み込む

  1. 拡張機能 ZIP をダウンロード → 解凍
  2. Chrome で chrome://extensions/ を開く
  3. 右上「デベロッパーモード」を ON
  4. 左上「パッケージ化されていない拡張機能を読み込む」→ 解凍したフォルダを選択
  5. 一覧に「STRATEGY-KIT Helper」が出れば成功

STEP 2：Google アカウントを連携する

  1. 拡張機能アイコンをクリック → 右側にサイドパネルが開く
  2. 上部の帯「はじめに · 3 ステップ」から「Google 連携」をクリック
  3. 開いた設定ページで「連携 / 再連携」→ テストユーザー登録済みの Gmail でログイン → 許可
  4. 「状態確認」で「連携済み」になれば成功
⚠️ 連携はテスト中アプリのため約 7 日で切れます。「未連携」と出たら故障ではなく、設定ページの「連携 / 再連携」を押し直せば復活します。未登録の Gmail は「アクセスをブロック」になるので講師に登録を依頼してください。

STEP 3：事業情報を入力する

  1. 設定ページの「事業情報」で 業種プリセット を選ぶ
  2. 「業種（自由入力）」「店舗・屋号」を入れて「保存」

STEP 4：マスタードキュメントを作る

  1. 設定ページの「マスタードキュメント」で「新規作成」をクリック
  2. 章立て（§0〜§9）の入った Google ドキュメントが自動生成される（テンプレの手動取り込みは不要）
  3. 「📄 開く」で確認

STEP 5：Gemini API キーを設定（任意・全自動を使う場合）

  1. 手動運用のみならスキップ可
  2. Gemini API ガイドに沿って AIza… のキーを取得
  3. 設定ページ「Gemini 設定」で登録（学習用途は「セキュア学習モード」推奨）

STEP 6：§0 を始める

  1. サイドパネルの「フェーズ」タブから「§0」を実行
  2. 結果をマスタードキュメントに記録（人間が選んで転記）
  3. あとは §1 → §9 まで同じ要領で進める

§8（KPI）まで進んだ方へ：計測クイックスタート

§8 で KPI を設計したら、次はその数字を実際に取りに行く番です。「翌週の月曜に先週の数字を見られる」状態を、最小の手間で作るためのガイドを用意しました。GA4・SNS インサイト・レジ／台帳・アンケートといった取得手段別のセットアップ、KPI ダッシュボードの雛形、週15分の振り返りテンプレまでを、無料の範囲・紙でもOKの形でまとめています（§8 まで進んでいない方は、まずセットアップガイドから）。

📊 計測クイックスタートを開く

v0.11 以前をお使いだった方へ

v0.11 までは、Apps Script のライブラリ登録・shim の貼り付け・Web App のデプロイ・拡張機能への GAS URL 登録が必要でした。現行の v0.12 では、これらの作業はすべて不要になりました。Google 連携（STEP 2）だけで動きます。旧バージョンの手順書（setup-guide-v0.11.html）は参照しないでください。
