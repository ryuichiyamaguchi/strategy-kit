# Slide Generation Playbook

> **これはスライド資料の内容ではなく、NotebookLM への作業指示集です。**
> ソースとして追加せず、各ステージの Chat 入力欄または Studio のプロンプト欄に貼り付けてください。
>
> ※ 本書に出てくる「スライド §N」はスライドデックの構成番号であり、マスター戦略書の §N（章番号）とは別物です。マスター戦略書の章は内容名（例: KPIツリー節）で指示します。

---

## 最初に1回だけ：共通カスタマイズ欄

> **この欄を先に埋めてください。** 各ステージのプロンプトには `★…★` という差し込み箇所があります。ここで決めた値を、その `★…★` に当てはめて（手で書き換えて）使います。一度決めれば、同じ値を各ステージに転記するだけで済みます。

| 差し込み記号 | あなたの値（記入例） | 当てはめる場所 |
|---|---|---|
| ★店舗名★ | （例）山口ボルダリングジム | ステージ 1・2・3 |
| ★業種★ | （例）クライミングジム | ステージ 1・3 |
| ★聴衆★ | （例）店舗オーナー本人 / 共同経営者 / 銀行担当者 | ステージ 3・5 |
| ★目的★ | （例）方針の意思決定 / 社内共有 / 融資相談での説明 | ステージ 3・5 |
| ★トーン★ | 既定：**落ち着いた親しみのある会話風（ビジネスとして簡潔）**。変えたいときだけ上書き | ステージ 3・5 |

- **★聴衆★・★目的★** は「誰に・何のために見せるか」。これでスライドの言葉づかいと厚みが変わります。
- **★トーン★** は読み上げ原稿（ステージ 5）と本文の語り口に効きます。指定が無ければ既定のまま使ってください。
- 各ステージのプロンプト内に `★…★` が出てきたら、この表で決めた値に置き換えてから送信してください。

## ステージ 1: 戦略整理

**挿入先**: NotebookLM の Chat 入力欄
**source が効くか**: はい

**このステージの目的**:
- 戦略書全体から、スライドに載せる「主役の数値・施策・KPI」を選び出す（要約ではなく取捨選択）
- ゴールの数値目標を、スライド §0（冒頭）の主役にできる形で確定させる

**判断基準（次へ進む前に確認）**:
- [ ] ゴールに「いつまでに・何を・いくつ」の数値目標が 1 つ以上ある
- [ ] 施策が「インパクト × 実行可能性」で上位 3 つに絞れている
- [ ] KPI が 3〜5 個に絞れ、各 KPI に目標値と現状値（または出典章番号）がある

---

★店舗名★（★業種★）のマーケティング戦略ドキュメントを読んで、以下を整理してください。
（マスター戦略書の章は内容名で指定します）

- ゴール（マスターの目標・数値ゴール）: 何を達成したいか（**数値目標を必ず抽出**。「いつまでに・何を・いくつ」の形に整える）
- 顧客・調査分析・統合（SWOT）: それぞれ 2〜3 行で要約
- 戦略策定・価値設計・施策設計: 施策を「**インパクト（売上・利益への効き）× 実行可能性（リソース・期間）**」で評価し、上位 3 つに絞る。落とした施策は理由を 1 行で添える
- KPI（マスターの KPIツリー節と PDCA 設計）: 測定指標と目標値の一覧。**測定可能性と先行指標性（結果が出る前に動く指標か）で 3〜5 個に絞る**

各項目は根拠となる箇所を引用して示してください。「整理した」で終わらせず、必ず上位 N 件への絞り込みと、その選定理由を示してください。

## ステージ 2: アウトライン確認

**挿入先**: NotebookLM の Chat 入力欄
**source が効くか**: はい

**このステージの目的**:
- 戦略資料の「読ませる順番」を決める。スライド §0 ゴールを冒頭に置き、結論から逆算する流れにする
- 章ごとの枚数配分で、戦略の重心（スライド §4 戦略・§5 戦術・§7 KPI）に枚数を厚く割り当てる
- ※ ここでの §N はすべて下記スライドデックの章番号。マスター戦略書の章番号とは別

**判断基準（次へ進む前に確認）**:
- [ ] スライド §0 ゴールが冒頭にあり、最後のスライド §9 決定ログまで「結論 → 根拠 → 実行 → 測定」の流れになっている
- [ ] 重心となるスライド §4・§5・§7 の枚数が、スライド §3・§8・§9 より厚い
- [ ] 総枚数が 15〜25 枚に収まっている

---

★店舗名★の戦略ドキュメントを基に、スライドデックの章立てを提案してください。
（以下の §N はスライドデックの章番号であり、マスター戦略書の章番号とは別です）

条件:
- スライド総数は 15〜25 枚を想定
- 章はスライド §0 ゴール → §1 顧客 → §2 提供価値 → §3 課題 → §4 戦略 → §5 戦術 → §6 体制 → §7 KPI → §8 リスク → §9 決定ログ の順
- 各章のスライド枚数（目安）を括弧内に示す。**戦略の重心であるスライド §4 戦略・§5 戦術・§7 KPI を厚く、スライド §3 課題・§8 リスク・§9 決定ログ を薄く配分する**
- 章立てのみ出力し、スライド本文は書かないこと

## ステージ 3: 初回 Slide Deck 生成

**挿入先**: NotebookLM Studio → Slide Deck → ステアリングプロンプト欄
**source が効くか**: はい

**このステージの目的**:
- ステージ 1・2 で絞った内容を、デザインガイドに沿った初回デックに落とす
- スライド §0 ゴールとスライド §7 KPI を「数値が主役」のスライドにする
- 共通カスタマイズ欄で決めた **★聴衆★・★目的★・★トーン★** を反映する
- ※ 以下の §N はスライドデックの章番号。マスター戦略書の章番号とは別

**判断基準（次へ進む前に確認）**:
- [ ] スライド §0 が数値目標を主役にしたゴールスライドになっている
- [ ] スライド §4 戦略の各施策に「インパクト × 実行可能性」の根拠が 1 行ある
- [ ] スライド §7 KPI が目標値と現状値の比較形式になっている
- [ ] 1 スライド 1 メッセージ・箇条書き 3〜5 点を守れている

> **💡 枚数が多いときのコツ（20 枚超）**
> NotebookLM は一度に生成できる枚数に上限があります。総枚数が 20 枚を超える見込みなら、**「§0〜§4 をまず生成 → 続けて §5〜§9 を生成」のように 20 枚ずつ分割**して複数回プロンプトを送ってください。分割しても章番号順・デザイン指定は各回で同じものを付けます。

---

あなたは戦略コンサルタント兼デザイナーです。以下の条件で Slide Deck を生成してください。

対象: ★店舗名★（★業種★）のマーケティング戦略
聴衆: ★聴衆★
目的: ★目的★
トーン: ★トーン★（既定は「落ち着いた親しみのある会話風（ビジネスとして簡潔）」）
スタイル: 添付の "STRATEGY ROUTE — Visual Design Guide" をブランドブックとして適用する
構成（スライドデックの章番号。マスター戦略書の章番号とは別）: §0 ゴール → §1 顧客 → §2 提供価値 → §3 課題 → §4 戦略 → §5 戦術 → §6 体制 → §7 KPI → §8 リスク → §9 決定ログ

ルール:
- 1 スライド 1 メッセージ
- 本文は箇条書き 3〜5 点まで
- フォントは BIZ UDPGothic / Noto Sans JP、数値は JetBrains Mono を優先
- 章扉は Deep Route (#10233D) の濃紺背景＋画面外へ切れる巨大な章番号＋Route Rail
- 本文は White / Route Mist (#F5F7FA) を基調にし、現在地は Route Blue (#3E72E8)、採用案・到達点は Waypoint Mint (#53C8BF) で示す
- 「濃紺の章扉 → 明るい結論 → 根拠 → 図解・数値 → 次章」の視覚リズムを作り、全ページを同じカード構成にしない
- 事実→示唆、優先度マトリクス、KPIダッシュボード、30/90日ロードマップはガイドの専用レイアウトを使う
- 事業固有の画像がソースにある場合だけ大きく使い、汎用ストック写真や装飾目的のAI人物画像は使わない
- 数値・KPI は必ず含める
- **スライド §0 ゴールは数値目標を最大級に大きく表示し、スライドの主役にする**
- **スライド §4 戦略の各施策には「インパクト × 実行可能性」での採用理由を 1 行添える**（並べただけにしない）
- **スライド §7 KPI は目標値と現状値を並べた比較形式にする**
- 上で指定した ★聴衆★・★目的★・★トーン★ に合わせて言葉づかいと説明の厚みを調整する
- 日本語で生成

## ステージ 4: デザイン / Revision

**挿入先**: NotebookLM Studio → Slide Deck → Revision 指示欄
**source が効くか**: いいえ（Revision 時はソースは参照されません）

**このステージの目的**:
- デザインを STRATEGY ROUTE ガイドに統一し、章扉・Route Rail・数値の強弱を整える
- ソースが効かないため、直したい数値・固有名詞を「直書き」で指示し、初回デックの誤り・空欄を確定値で埋める

**判断基準（次へ進む前に確認）**:
- [ ] アクセント色・フォント・余白がガイド通りに揃った
- [ ] スライド §7 KPI / ユニットエコノミクスの数値が、戦略書の確定値で直書き修正されている
- [ ] 「◯ / △」や空欄のまま残っているプレースホルダがない

---

⚠ このステージではソースは参照されません。数値・固有名詞はプロンプトに直接記述してください。

以下の修正を適用してください:

デザイン:
- 表紙と章扉を Deep Route (#10233D) の濃紺背景にし、白文字＋右端で15〜25%切れる巨大な章番号を置く
- 章扉下部に §0〜§9 の Route Rail を置き、現在章を Waypoint Mint (#53C8BF) で示す
- 本文背景は White / Route Mist (#F5F7FA)、本文文字は Deep Route (#10233D)
- 現在地・比較の主系列は Route Blue (#3E72E8)、採用案・到達点は Waypoint Mint、未確定・注意だけ Signal Amber (#F1A84A)
- 見出しフォントを BIZ UDPGothic 700、本文を Noto Sans JP、数値を JetBrains Mono 600 に変更
- AI風の紫グラデーション、意味のない光彩、強いシャドウ、カード内カードを削除
- 同じ3カード構成が3枚以上連続しないよう、結論・根拠・数値・図解・ロードマップの型を使い分ける
- 箇条書きは 3〜5 点に絞る

レイアウト:
- 各スライドのタイトルは 20 字以内
- 余白を広げてホワイトスペースを確保
- 図表はテキストの右側または下に配置

数値の直書き修正（例 — 自店の確定値に置き換えて指示すること）:
- ユニットエコノミクス（マスター戦略書 §7-4）のスライドを、次の確定値に差し替えてください。
  - CAC（顧客獲得単価）: 8,000〜14,000 円（レンジ表示のまま大きく表示）
  - LTV（顧客生涯価値）: 65,000 円
  - Payback（回収期間）: 4.2 ヶ月
  - LTV / CAC 比: 約 5.4 倍（Waypoint Mint の面＋Deep Route文字で最重要値として強調）
- ※ 推定値はレンジ表示（例「CAC 8,000-14,000円」）を維持し、確定済みの値は単一値で表示してください。

## ステージ 5: 読み上げ原稿の生成（任意）

**挿入先**: NotebookLM の Chat 入力欄（確定したスライド構成を貼り付けて依頼する）

**このステージの目的**:
- 完成したデックを「人前で話す」ための読み上げ原稿（スピーカーノート）を用意する
- 共通カスタマイズ欄で決めた **★トーン★・★聴衆★・★目的★** に合わせた語り口にする
- スライドだけ配るのではなく、発表・商談・社内共有で「そのまま話せる」状態にする

**判断基準（完了と見なす条件）**:

- [ ] 原稿が「読み込んだソースに無い数値・一般論」を勝手に足していない（ソースとスライドの範囲内）

## ステージ 6: 最終調整

**挿入先**: NotebookLM 外での作業（PPTX / PDF ダウンロード後）
**source が効くか**: —（NotebookLM の外で行う）

**このステージの目的**:

- 配布前に「章ごとの現在地・主役の数値・採用理由・次の一手」が視覚的に読めるかを最終確認する

**判断基準（完了と見なす条件）**:

---

NotebookLM から PPTX または PDF をダウンロードしたら、以下の手順で最終調整してください:

1. Google Slides で開く: PPTX を Drive にアップロードして Slides で開く
2. フォント確認: 見出し BIZ UDPGothic、本文 Noto Sans JP、数値 JetBrains Mono の役割を確認
3. ブランド色確認: Deep Route (#10233D) / Route Blue (#3E72E8) / Waypoint Mint (#53C8BF) / Signal Amber (#F1A84A) の使い分けを確認
4. 余白・整列: スライド全体の上下左右マージンを揃える
5. KPI スライド: 数値を大きく表示し、目標値と現状値を並べて比較形式に
6. PDF でエクスポートし、受講者に配布
