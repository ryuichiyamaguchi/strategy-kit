Gemini 設定

全自動生成と図解自動生成で使います。学習用途では「セキュア学習モード」を推奨します。

無料枠の API key だけで §0〜§9 を最後まで実行できます。課金 API key を設定すると、「実行モードを管理」で高精度モデル（Gemini 3.1 Pro）と画像系図解が選べるようになります。

API キーをまだ持っていない方へ（数分・カード登録不要）

  1. 下のボタンで Google AI Studio の「API キー」画面を開き、Google アカウントでログインします。
  2. 初めて使う場合は利用規約に同意すると、プロジェクトとキーが自動で作られます。キーが無いときは「API キーを作成」を押します。
  3. 表示されたキーをコピーし、この下の「セキュア学習モード」の欄に貼り付けて「proxy に key を設定」を押します。
Google AI Studio でキーを作る

会社の Google アカウントで「このプロジェクトでキーを作成する権限がありません」と出た場合は、管理者に権限を依頼するか、個人の Google アカウントで作成してください。キーはパスワードと同じ扱いです。人に送ったり、画面共有で映したりしないでください。

直接 API key モード

注意: API key をこの端末の local storage に保存します。学習用の無料枠または少額上限の key にし、Google AI Studio / Cloud Console 側で Generative Language API のみに制限し、利用上限も絞ってください。漏れても被害が小さくなる設定が前提です。セキュリティ上、最も推奨される方法ではありません。

セキュア学習モード

マスタードキュメントに紐づいた Apps Script proxy を作成し、Gemini API key は Apps Script の Script Properties に保存します。拡張機能側には key を保存しません。初回だけ Apps Script 側の承認が求められる場合があります。

画像系図解（Nano Banana・きれい・編集不可）を proxy で使う場合、2026-05-26 以前に作成した proxy は「Gemini proxy を作成」から再作成してください。

DeepSeek 設定（任意）

「実行モードを管理」のモデル選択で DeepSeek V4 Flash を選んだときだけ使います。 未設定でも Gemini での動作には影響しません。

DeepSeek はウェブ検索と画像生成に対応していません。§0 のプレリサーチ（検索あり）は検索なしで実行され、図解の画像生成には Gemini の key が必要です。

注意: API key をこの端末の local storage に保存します。DeepSeek のダッシュボードで利用上限を絞った key を使ってください。

このツールについて

AIの出力を直接マスタードキュメントに書き込まないでください。必ず別ファイルに残し、人間が選別して転記する運用を守ってください。

最新版・更新

GitHubで配布している最新版を確認できます。ZIP版は、ダウンロード後に解凍フォルダを差し替え、 chrome://extensions/ のこの拡張機能カードで「再読み込み」を押してください。

Windows / macOS のChromeでは、GitHub版を拡張機能から無操作で上書き更新することはできません。 Web Store版は、新しい版の審査・公開後にChromeが順次自動更新します。
